Async/Await vs .then()

.then() uses a promise chain. It's often harder to read with complex logic.

fetch(url)
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

async/await looks synchronous and is cleaner for error handling with try/catch.

try {
  const res = await fetch(url);
  const data = await res.json();
  console.log(data);
} catch (err) {
  console.error(err);
}
