Revision: MySQL Indexes

Understanding the difference between Clustered and Non-Clustered Indexes.

Clustered Index

  • Stores the actual data rows in the leaf nodes.
  • Only one per table (usually the Primary Key).
  • Faster for retrieving full records (no extra lookup).
  • Analogy: A dictionary (words are sorted, definitions are right there).

Non-Clustered Index

  • Stores a pointer to the data row (usually the PK).
  • Can have multiple per table.
  • requires a second lookup (to valid the pointer) to get full data.
  • Analogy: The index at the back of a book (points to the page number).
